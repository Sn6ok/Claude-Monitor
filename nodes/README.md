# Вузли (Nodes)

Вузол — маленьке розширення Claude Monitor. Працює як мод до гри: поклали
каталог у папку вузлів — він з'явився в застосунку, прибрали — зник.
Нічого перезбирати чи правити в коді не треба.

```
%USERPROFILE%\.claude-monitor\nodes\
└── system-info\
    ├── node.json     опис: назва, що запускати, як часто
    └── run.ps1       будь-яка програма, яка друкує JSON у stdout
```

## Встановити вузол

```powershell
.\scripts\install-node.ps1 .\nodes\system-info
```

Або просто скопіюйте каталог вузла в `%USERPROFILE%\.claude-monitor\nodes`.
Bridge перечитує папку сам, щонайбільше за 10 секунд — перезапуск не потрібен.

Що вже є в цьому каталозі:

| Вузол | Що показує |
|---|---|
| [`system-info`](system-info) | процесор, вільна пам'ять, час роботи ноутбука |
| [`disk-space`](disk-space) | вільне місце на дисках |
| [`claude-click`](claude-click) | мишка для Claude Code: пише в чаті, куди він тиснув |
| [`template`](template) | порожня заготовка для власного вузла |

## Написати свій

`node.json`:

```json
{
  "name": "Моя картка",
  "run": "run.ps1",
  "intervalSec": 30,
  "timeoutSec": 10
}
```

`run.ps1` друкує в stdout один об'єкт JSON:

```json
{"status":"ok","lines":[{"label":"Підпис","value":"значення"}],"text":"довільний текст"}
```

Мова будь-яка: `.ps1` запускається через PowerShell, `.js` — через Node,
`.py` — через Python, `.exe` — напряму.

Вузол може ще й підписувати команди, які виконує Claude Code, — так працює
`claude-click`:

```json
"commands": [
  { "match": "click.py", "args": ["x", "y", "label"], "text": "Натискаю: {label}" }
]
```

Повний опис полів і меж — [docs/nodes.md](../docs/nodes.md).

## Безпека

Вузол — це **чужий код, який виконується на вашому комп'ютері з вашими
правами**. Тому:

* вузли беруться лише з вашої папки — Bridge нічого не завантажує з мережі;
* кожен запуск обмежений часом і розміром виводу;
* вузол не отримує ні ключів, ні коду підключення, ні вмісту ваших сесій;
* усе, що вузол надрукував, проходить те саме маскування секретів, що й
  звичайні події.

Ставте лише ті вузли, які прочитали або яким довіряєте — як і моди до гри.
