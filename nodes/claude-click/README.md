# Claude Click

Мод, який дає Claude Code мишку — і пише в застосунку, куди саме він тиснув.

```text
  [10:24:31] ⚙ Claude Click
             Натискаю: Файл
```

Клік робить сам Claude Code: знімає екран, знаходить потрібну кнопку й
запускає `click.py`. Claude Monitor бачить цю команду в транскрипті й додає
рядок **у чат тієї самої задачі** — вигадувати, кому належить клік, не
доводиться.

## Встановлення

```powershell
.\scripts\install-node.ps1 .\nodes\claude-click
pip install -r "$env:USERPROFILE\.claude-monitor\nodes\claude-click\requirements.txt"
```

Далі скажіть Claude Code, де лежить програма — додайте в `CLAUDE.md` свого
проєкту (або в `~/.claude/CLAUDE.md`) рядки з розділу «Як цим користується
Claude Code» нижче.

## Команди

| Команда | Що робить |
|---|---|
| `python screenshot.py` | знімок у `screenshots/screen.png`, друкує шлях |
| `python click.py X Y "Файл"` | лівий клік у точку знімка; третій аргумент — на що тиснемо |

`X Y` — координати **на знімку**, не на екрані: перерахунок робить сам
скрипт (через `screenshots/last.json`).

Третій аргумент нічого не змінює в кліку — він лише потрапляє в чат
застосунку. Без нього рядок буде «Натискаю: точка 640, 300».

## Як цим користується Claude Code

```markdown
## Claude Click
Мишка: `%USERPROFILE%\.claude-monitor\nodes\claude-click`

1. `python "%USERPROFILE%\.claude-monitor\nodes\claude-click\screenshot.py"`
2. Відкрий PNG (Read) і знайди центр потрібного елемента.
3. `python "%USERPROFILE%\.claude-monitor\nodes\claude-click\click.py" X Y "Файл"`
   Третім аргументом завжди пиши, на що тиснеш, — це видно в Claude Monitor.
4. Знову знімок і перевір результат.

Правила: координати лише з останнього знімка; один клік — одна перевірка;
цілитись у центр; перед кліком, який видаляє, надсилає, купує чи публікує —
спитати користувача; два промахи поспіль — зупинитись і пояснити.
```

## Картка вузла

Над задачами Claude Monitor показує картку: скільки кліків було сьогодні,
який останній і коли. Журнал `clicks.log` пише сам `click.py` у цю ж папку,
зберігаються лише останні записи.

## Межі

* Лише основний монітор.
* Не можна клікати у вікна, запущені від адміністратора, та в діалоги UAC.
* Вікно Claude Code може перекривати потрібну програму — це вирішує людина.
* Рядок у чаті обмежений 160 символами, як і будь-який рядок вузла.

## Безпека

Мод запускає мишку на вашому комп'ютері з вашими правами — як і будь-який
вузол (див. [docs/nodes.md](../../docs/nodes.md)). Claude Monitor при цьому:

* не передає на телефон ні знімків екрана, ні координат вікон — лише рядок
  «Натискаю: …»;
* маскує секрети в цьому рядку так само, як у звичайних подіях;
* нічого не натискає сам: усі кліки робить Claude Code на вашу вимогу.
